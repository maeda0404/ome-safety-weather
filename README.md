# 青梅地域 安全・気象情報 draft-01

1920×1080横型サイネージ。正式現場名・住所・座標は画面に表示しません。

## 公開前に必須
1. `config.json` の `latitude` / `longitude` を正式確認した対象地点の値へ変更。
2. `python update_data.py` を実行し、サンプルの `data/current.json` を実データで置換。
3. 青梅市の対象地点について、内水浸水想定区域を公式地図で確認。
4. 気象庁の青梅市向け警報・注意報区域コードを確認後、雷・乾燥・公式警報連携を追加。
5. Chrome/Edgeの1920×1080で表示確認し、サイネージ実機で再確認。

## 仕様
- 通常画面: 気温、天気、総合判定、降水確率、降水量、風速、最低気温、日没
- 閾値（仮）: 降水確率60%、最低気温5℃、強風10m/s、暴風20m/s、大雨10mm/h
- 重大条件は即時全画面。その他は毎時00〜10分。複数は20秒ローテーション。
- 5分ごとにJSON再取得。正常データをlocalStorageへ保存。
- 1時間未満=通信正常、1〜3時間=更新遅延、3時間以上=通信失敗。
- 土砂災害判定は今回対象外。
